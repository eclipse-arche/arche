# ArchE Open-Source Platform

The project contains utilities (languages and solutions) which we developed as part of ArchE but which are relevant for other MPS-based projects.


### Features
- `tech.cariad.arche.oss.platform.userscripts` - enhancements of MPS console-scripts
- `tech.cariad.arche.oss.platform.structureview` - plugin to customize structure-view and outline
