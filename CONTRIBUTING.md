# Contribution Guidelines

We welcome all contributions from the community! Please check out the [Disclaimer](README.md#disclaimer) chapter.

- Follow the Eclipse Contributor Agreement (ECA) guidelines and create an Eclipse account. For more details, see [ECA Legal Page](https://www.eclipse.org/legal/eca/).
- Fork the repository and create your feature branch.
- Apply your changes and adapt the build solution of the effected subprojects accordingly.
- Ensure your code is well-documented and tested.
- Submit a pull request with a clear description of your changes.

## Contact

For more information, visit the [project page](https://projects.eclipse.org/projects/automotive.arche) and join the discussion on [Slack](https://join.slack.com/t/sdvworkinggroup/shared_invite/zt-3c5ied1nk-Mk87s4kOX7ipcNo_VktlWg) in the [#arche-community](https://sdvworkinggroup.slack.com/archives/C09C9S065V5) channel.
